# Cube Split Timer Recording Feature Inventory

この資料は YouTube Shorts 用の自動画面録画で使うために、公開画面と録画向きの機能だけを整理したものです。秘密情報、環境変数、APIキー、認証情報は含めません。

確認した主なコード:

- `src/App.tsx`
- `src/lib/recordingMode.ts`
- `src/analyzer/AnalyzerPage.tsx`
- `src/learn/LearnPage.tsx`
- `src/learn/AlgorithmPlayer.tsx`
- `src/learn/learningData.ts`
- `src/lib/stats.ts`

## recording=1 の現在の挙動

`?recording=1` を付けると、録画向けに以下が有効になります。

- デモ用スクランブルを固定表示
- デモ用ソルブ履歴を固定表示
- 通知、ログイン誘導、共有通知、チュートリアル、undo toast を非表示
- ログイン状態を使わずゲスト表示に寄せる
- テーマは dark 固定
- Analyzer の速度は `1x` 固定
- Analyzer の回転音は無効
- 9:16 録画でタイマーや3D再生が見えやすい余白に調整

## Shortsで優先して見せる機能

1. タイマーとスクランブル
2. 記録分析
3. Learn F2L / OLL / PLL
4. Analyzer 3D再生
5. F2L強調または回転記号学習

ログイン、フレンド、チャット、Admin は録画素材から外すのが安全です。
