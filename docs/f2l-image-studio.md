# F2L Image Studio

F2L学習用の画像を作るためのローカル専用ツールです。本番アプリの画面には出さず、`127.0.0.1` だけで起動します。

## 起動

```bash
npm run f2l:studio
```

開くURL:

```text
http://127.0.0.1:5187/
```

## できること

- `src/assets/learn/f2l` のPNGファイル名からF2L手順を読み込む
- その手順の逆状態を3Dキューブで表示する
- ドラッグ、スライダー、ホイールでカメラ角度、ズーム、表示位置を調整する
- `PNG Size` は 48 から 2048px まで指定できる
- Learnのカード表示では拡大されるため、通常は `512` 推奨
- 軽さを優先する場合でも `320` 以上にするとぼやけにくい
- `最初の上段をグレー` では、スクランブル前に上段だったピースだけをグレーにして、その色を保持したままケース状態を作る
- `PNG保存` で現在の見た目をPNGとして保存する
- 同じ名前がある場合は上書きする
- 作成済み画像を右側の一覧で確認する

## 保存先

```text
src/assets/learn/f2l-generated
```

ファイル名は元のF2L画像と同じ形式です。

例:

```text
Lp_U_L_U_Lp_U_L_Up_yp_R_U_Rp.png
```

## 画質と重さ

このツールの画像はPNGで保存します。F2L 41枚ぶんでも、512px程度なら現実的なサイズに収まりやすく、赤青黄などの境目もにじみにくいです。

すでに100pxなど小さいサイズで保存した画像は、あとから拡大しても本当の画質は戻りません。同じケースをStudioで開き、`PNG Size` を512にしてもう一度保存すると、同じファイル名で高画質版に上書きされます。

どうしても容量を下げたい場合は、あとでWebP版を別途生成する方法もあります。ただし教材画像では色の境目が少しにじむことがあるため、まずはPNGのまま512pxで作る方針にします。

## 注意

- このツールはローカル制作専用です。
- Vercel公開用の通常ページには追加していません。
- 生成した画像を本番Learnで使う場合は、確認後に `src/assets/learn/f2l` 側へコピーするか、読み込み先を切り替えてください。
